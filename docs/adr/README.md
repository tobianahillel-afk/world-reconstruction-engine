# Architecture Decision Records

Use ADRs only for decisions with durable architectural impact, especially custom algorithm implementations, core dependency changes, licensing-sensitive choices, data-model invariants and irreversible public interfaces.

ADRs are not required for routine implementation details already covered by an active work item.
